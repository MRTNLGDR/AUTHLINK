# AUTHLINK — AIIA Suite

AuthLink é a autoridade de identidade, sessão, consentimento, comunicação segura e navegação entre apps da AIIA Suite.

Este repositório consolida a especificação V3, o inventário de telas aprovadas, a base mobile-first e o início da implementação Rust/WebMobile/Desktop.

## Estado

- documentação unificada V3: em `docs/spec-v3/`
- referências visuais aprovadas: em `docs/ui-approved/`
- web app mobile-first: em `apps/web/`
- gateway Rust: em `services/gateway/`
- domínio/contratos Rust: em `crates/`
- infraestrutura local: em `infra/`
- upstreams e licenças: em `vendor/`

> O alvo é composição por tecnologias open source permissivas, com AuthLink como autoridade única de identidade/sessão e integrações separadas por adapters.
